# 📱 Mobile Sales Analytics Dashboard | Power BI

This project is an interactive **Power BI dashboard** developed as part of my **Masters**.  
The dashboard analyzes mobile phone sales data to deliver **business-oriented insights** across brands, customers, and regions.

---

## 🔍 Project Overview

The dashboard provides insights into:
- Overall sales performance using KPIs
- Revenue and units sold by **brand and mobile model**
- **Monthly revenue trends** to identify seasonality
- **City-wise sales distribution** using map visualization
- Customer segmentation by **age group**
- Transaction analysis by **payment method**
- Relationship between **customer ratings and revenue**

---

## 📊 Key KPIs
- Total Revenue  
- Total Units Sold  
- Total Transactions  
- Average Customer Rating  
- Average Order Value  

---

## 🛠 Tools & Technologies
- Power BI Desktop  
- Power Query (data cleaning & transformation)  
- DAX (measures, KPIs, calculated columns)  
- Data Visualization & Dashboard Design
